# ShopSmart – E-commerce Website

## Experiment 4: Front End Development Frameworks

### Aim
To design and develop a responsive e-commerce website homepage using HTML, CSS Flexbox, CSS Grid, animations, and JavaScript.

### Technologies Used
- HTML5
- CSS3
- JavaScript
- Visual Studio Code
- Git and GitHub

### Features
- Modern and responsive homepage
- Eight product cards with images and prices
- Product categories and filtering
- Search products by name
- Add-to-cart functionality
- Shopping cart counter and total price
- CSS hover effects and animations
- Responsive layout for desktop, tablet, and mobile
- Product images loaded from Unsplash

### Project Structure

```text
EXP4-Ecommerce/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### How to Run the Project
1. Download and install Visual Studio Code.
2. Open the `EXP4-Ecommerce` folder in VS Code.
3. Install the Live Server extension.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.
6. Use the search bar, category filters, and cart to test the website.

### How to Upload to GitHub

Run these commands in the VS Code terminal:

```bash
git init
git add .
git commit -m "Create ShopSmart e-commerce website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/EXP4-Ecommerce.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username.

### Result
Successfully developed a responsive e-commerce website homepage using HTML, CSS, and JavaScript, featuring product images, category filters, product search, and shopping cart functionality.

### Note
This is an educational front-end project. The shopping cart is a demonstration and does not process real payments or store orders permanently.
